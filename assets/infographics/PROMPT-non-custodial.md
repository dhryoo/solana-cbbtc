# Infographic 1 — Non-custodial flow (비수탁 자금 흐름)

목표: "이 앱은 당신의 자금이나 키를 보관하지 않는다. 자금은 당신이 직접 서명할 때만,
당신의 지갑에서 Kamino 의 감사받은 스마트컨트랙트로 직접 간다" 를 한눈에 보여주는 흐름도.

## Image prompt (영문 — 이미지 AI 에 입력)

```
A clean, modern, flat-design horizontal infographic for a mobile fintech app, on a
white background, with generous padding. Three rounded-rectangle nodes connected
left-to-right by simple arrows, showing a money flow:

1) Left node: a smartphone / wallet icon holding a bitcoin coin (orange ₿, #F7931A).
   Label "Wallet".
2) Middle node: a fingerprint + lock / hardware security icon representing the user
   approving and signing. Label "You sign".
3) Right node: a shield with a checkmark over a smart-contract / vault icon,
   representing an audited protocol. Label "Kamino".

Below or above the arrow between node 1 and node 3, show a small, semi-transparent
"app" chip that the flow passes THROUGH but does not stop at, with a tiny badge that
reads "never holds funds" — communicating the app is only a pass-through, not a custodian.

Style: minimal, friendly, geometric, soft rounded corners, subtle drop shadows.
Primary color Solana purple (#9945FF) for nodes/arrows; bitcoin orange (#F7931A)
only for the ₿ coin. White background, high contrast, no gradients heavier than subtle.
No paragraphs of text — only the short labels mentioned. 16:10 aspect ratio. Vector / flat illustration look.
```

## 의도 (검수 포인트)

- 자금이 **지갑 → (내 서명) → Kamino** 로 흐르고, 앱은 거쳐가기만 함("never holds funds").
- 보안/서명 강조(지문·자물쇠), 감사받음 강조(방패+체크).
- 텍스트는 짧은 영어 라벨만 (Wallet / You sign / Kamino / never holds funds).
