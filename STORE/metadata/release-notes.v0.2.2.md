# Release notes — v0.2.2 (versionCode 14)

dApp Store 제출 시 "release notes / What's new" 필드에 복사.
v0.2.1(친절한 오류 안내) 대비 증분 업데이트 — Earn/Swap 거래 내역과 USDC 잔액 표시가 핵심.

## 한국어 (ko)

```
v0.2.2 — 거래 내역 + USDC 잔액 한눈에

• 거래 내역 추가 — 홈에 최근 활동, 설정에 전체 내역 (Swap·Earn 자동 분류, Solscan 딥링크)
• 홈에 USDC 잔액 카드 추가 — cbBTC·SOL·USDC·SKR 한눈에
• Repay 폼에 지갑 USDC 잔액 표시 — 상환 가능 금액 즉시 확인
• 설정의 앱 버전 자동 동기화 — 매 릴리스에서 정확한 버전 노출
• 비수탁 유지 — 자금·키는 Seed Vault, 백엔드·트래커 없음
```

## English (en)

```
v0.2.2 — Transaction history + USDC at a glance

• New transaction history — Recent activity on Home, full list in Settings (auto-classified Swap/Earn, Solscan deep links)
• USDC balance card on Home — cbBTC, SOL, USDC, and SKR side by side
• Wallet USDC shown on Repay — see at a glance what you can repay
• Settings now shows the live app version (auto-synced with each release)
• Self-custody as always — keys stay in Seed Vault, no backend or trackers
```
