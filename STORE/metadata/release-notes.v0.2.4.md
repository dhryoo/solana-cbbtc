# Release notes — v0.2.4 (versionCode 16)

dApp Store 제출 시 "release notes / What's new" 필드에 복사.

v0.2.2(거래 내역 + USDC 잔액) 이후 누적된 변경을 한 번에 묶음. v0.2.3 (versionCode 15)
은 git 상 존재하지만 빌드/제출되지 않아 그 내용도 모두 v0.2.4 에 포함됨.

## 한국어 (ko)

```
v0.2.4 — 더 친절한 안내 + 사전 감지 + 업데이트 알림

• 거래 직전에 미리 알려요 — 지갑 세션이 오래되면(12시간 경과 또는 직전 실패) Earn 탭 상단 배너로 "재연결" 안내
• 친절한 오류 안내 추가 — 지갑 응답 시간 초과, 상환할 부채 없음을 raw 오류 대신 명확한 메시지로
• 새로고침 표시기 가시성 개선 — 라이트/다크 양쪽 모두 잘 보이는 브랜드 보라색
• 새 버전 알림 — 새 버전이 올라오면 앱 안에서 바로 안내(업데이트 / 변경사항 보기 / 나중에 / 이 버전 무시)
• 앱 소개의 로드맵 보강 — Phase 2.5(멀티 프로토콜 비교), Phase 3(Lightning Network 결제) 안내 추가
• 비수탁 유지 — 자금·키는 Seed Vault, 백엔드·트래커 없음
```

## English (en)

```
v0.2.4 — Friendlier notices, pre-flight checks, update awareness

• Get warned before a transaction breaks — Earn shows a "Reconnect" banner when your wallet session is older than 12 hours or just failed
• Two new friendly notices — wallet timeout and "nothing to repay" replace raw errors with clear guidance
• Pull-to-refresh spinner is now clearly visible in both light and dark themes (brand-colored)
• In-app update awareness — when a new version is published, you'll see it inside the app with options to get the update, view changes on GitHub, defer, or ignore the version
• Roadmap in About expanded — Phase 2.5 (multi-protocol comparison) and Phase 3 (Lightning Network payments) explained
• Self-custody as always — keys stay in Seed Vault, no backend or trackers
```
