# Release notes — v0.2.0 (versionCode 12)

dApp Store 제출 시 "release notes / What's new" 필드에 복사. (포털 한도에 맞춰 간결 유지)

## 한국어 (ko)

```
v0.2.0 — cbBTC 렌딩(Earn) 추가

• Kamino 기반 cbBTC 공급·인출, USDC 차입·상환
• health(건전성)·청산가 위험 표시, 첫 차입 시 위험 동의
• 최대 차입 가능액 표시 + 안전 80% 자동 입력(보수적 차입)
• 작동 방식·투명성·위험을 설명하는 안내 화면(인포그래픽)
• Swap: 보유량·최소·최대(MAX) 입력 표시, 안내 화면 추가
• 더 친절해진 안내 — SOL 부족·지갑 재연결·일시적 시세 지연을 쉬운 메시지로(raw 오류 제거)
• 비수탁 유지 — 자금·키는 Seed Vault, 백엔드·트래커 없음
```

## English (en)

```
v0.2.0 — cbBTC lending (Earn)

• Earn: supply / withdraw cbBTC and borrow / repay USDC via Kamino
• Health & liquidation-price risk display; consent prompt on first borrow
• Max-borrowable shown + one-tap safe 80% fill for conservative borrowing
• In-app guides (how it works, transparency, risk) with infographics
• Swap: balance / min / MAX shown, plus a new guide screen
• Friendlier messages — clear guidance for low SOL, wallet re-auth, and brief oracle delays (no more raw errors)
• Self-custody as always — keys stay in Seed Vault, no backend or trackers
```
