# Release notes — v0.2.3 (versionCode 15)

dApp Store 제출 시 "release notes / What's new" 필드에 복사.
v0.2.2(거래 내역 + USDC 잔액) 대비 증분 업데이트 — 폴리시 위주.

## 한국어 (ko)

```
v0.2.3 — 더 친절해진 안내 + 화면 표시 개선

• 지갑 응답 시간 초과 친절 안내 — 지갑 앱이 시간 안에 응답하지 못한 경우 raw 오류 대신 안내 메시지
• 새로고침 표시기 보임 개선 — 라이트/다크 양쪽에서 모두 잘 보이는 브랜드 보라색으로
• 앱 소개의 로드맵 보강 — 다음 단계(Lightning Network 결제 등) 안내 강화
• 비수탁 유지 — 자금·키는 Seed Vault, 백엔드·트래커 없음
```

## English (en)

```
v0.2.3 — Clearer notices, better visibility

• Wallet timeout friendly notice — if the wallet app doesn't respond in time, you see a clear note instead of a raw error
• Pull-to-refresh spinner is now clearly visible in both light and dark themes (brand-colored)
• Roadmap in About expanded — clearer picture of what's coming next (Lightning Network payments, multi-protocol lending)
• Self-custody as always — keys stay in Seed Vault, no backend or trackers
```
