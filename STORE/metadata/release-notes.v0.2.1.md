# Release notes — v0.2.1 (versionCode 13)

dApp Store 제출 시 "release notes / What's new" 필드에 복사.
v0.2.0(versionCode 12, cbBTC 렌딩 출시) 대비 증분 업데이트 — 친절한 오류 안내가 핵심.

## 한국어 (ko)

```
v0.2.1 — 더 친절해진 안내 메시지

• raw 오류 대신 쉬운 안내 — SOL 부족(계정 보증금·수수료), 지갑 재인증, 일시적 시세 지연
• 지갑 승인 취소 시에도 무서운 오류 대신 간단한 안내
• v0.2.0(cbBTC 공급·인출·차입·상환)에 이은 렌딩(Earn) UX 다듬기
• 비수탁 유지 — 자금·키는 Seed Vault, 백엔드·트래커 없음
```

## English (en)

```
v0.2.1 — clearer, friendlier messages

• Friendly guidance instead of raw errors — for low SOL (account rent & fees), wallet re-authorization, and brief price-oracle delays
• Cancelling a wallet approval now shows a simple note, not a scary error
• Lending (Earn) UX polish on top of the v0.2.0 cbBTC supply/borrow release
• Self-custody as always — keys stay in Seed Vault, no backend or trackers
```
